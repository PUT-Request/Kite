# Kite

A Discord bot that acts like a real person — with opinions, hobbies, and zero filter.

## Features

- Casual, unhinged personality (swears, roasts, hyps)
- Shell access, web search, file management
- Notion, GitHub, Dropbox integrations
- Email sending/receiving
- RSS feeds, bookmarks, reminders
- Static site deployment
- MCP tool support

## Setup

Ask your preferred coding assistant to help you set it up.
